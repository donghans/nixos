# 장부 #142 — psys ≈ b·pkg 의 b 는 날이 달라도 덮개 닫힘·배터리에서는 거의 같아(2.29~2.59) 다른 날의 b 를 적용해도 한가한 창의 흔들림이 크게 줄지만, 덮개 열림에서는 그렇지 않다…

## 결론

psys ≈ b·pkg + c 의 b 는 날이 달라도 덮개 닫힘·배터리에서는 거의 같아(2.29~2.59) 다른 날의 b 를 적용해도 한가한 창의 흔들림이 약 10배 줄지만, 덮개 열림에서는 b 가 날마다 달라(3.3~4.2) 다른 날의 b 로는 줄어들지 않는다 — R2 의 「다른 시험의 b 적용」 검증.

## 상세

**psys ≈ b·pkg + c 의 b 는 날이 달라도 덮개 닫힘·배터리에서는 거의 같아(2.29~2.59) 다른 날의 b 를 적용해도 한가한 창의 흔들림이 약 10배 줄지만, 덮개 열림에서는 b 가 날마다 달라(3.3~4.2) 다른 날의 b 로는 줄어들지 않는다.**
#137 의 한계(b 를 같은 창에서 구해 소음 감소가 부풀려졌다)를 확인하려고, 노트북 observe L0 표본(2026-10-20~28, 표본 간격 2~30초)을 120초 창으로 묶어(한가한 상태 `state=low` 이고 덮개·AC 가 창 안에서 같은 것만, 1,949개) 날짜를 한 개씩 빼고 나머지 날로 b 를 구해 뺀 날에 적용했다(자기참조 없음).
덮개 닫힘·배터리(753창·5일): 날마다 구한 b 는 2.29~2.59, 전체 2.42. 뺀 날에 적용한 창 psys 의 흔들림(표준편차)은 0.32~0.96 W → 0.023~0.098 W 로 줄었고, 그 날의 평균 오차(날짜 편향)는 −0.053~+0.086 W 였다.
덮개 닫힘·AC(978창·6일): b 2.41~3.34(충전 상태가 섞여 날마다 다를 수 있다 — 미확인). 교차 적용 잔차 0.022~0.171 W, 날짜 편향 −0.16~+0.49 W(50창뿐인 날 하나가 +0.49 W).
덮개 열림·AC(198창·4일, 창이 적음): b 3.3~4.2(#137 의 열림·AC 시험 4.7~4.9 와도 다름). 교차 적용 잔차 0.21~0.85 W, 날짜 편향 −1.30~+1.12 W — **열림에서는 다른 날의 b 를 쓸 수 없다.**
pkg 없이 공변량만(pc10·intr_s·mhz·soc, 전체 적합)으로는 닫힘에서 잔차 0.25 W(원 1.2 W)까지 줄지만 pc10·깨움·주파수는 pkg 의 대리 변수라 독립 설명이 아니다. **온도는 표본에 없어 공변량으로 못 썼다**(수집된 적 없음).
적용: `observe/ab/abab_rapl.py` 에 `--b <값>`(또는 환경변수 `ABAB_RAPL_B`)을 주면 psys A−B 를 「CPU 패키지 몫 + 패키지 밖 몫」으로 나눠 보인다(이 행과 함께 추가, 테스트 포함). 덮개 닫힘·배터리는 b≈2.4, 열림은 시험마다 그 시험에서 구한다.
한계: 한가한 창만(일하는 상태 제외), 시험 구간이 아닌 상시 표본, 날짜 5~6개라 b 가 날마다 달라지는 원인(충전 상태·밝기·네트워크)을 가르지 못했다. 닫힘·배터리의 날짜 편향 ±0.09 W 는 이 방법으로 가릴 수 있는 효과의 하한이다.
근거: 노트북 observe 표본 백업(`~/power-evidence-backup/laptop-observe-samples-20261028.tar.gz`), 분석 스크립트 `_lab/netoff/r2_cross_day.py`(`python3 -I r2_cross_day.py <표본 폴더>`).
