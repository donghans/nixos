# 장부 #55 — 실제 작업(저와 대화하며 nixos 수정·빌드)에서 nixup 빌드의 에너지 비중은 작다

> 장부 #55 행. 원본 `power-evidence.md` 표의 한 줄을 열 단위로 나눈 것이다(내용 변경 없음, 문장 단위로 줄만 바꿈). 새 행은 이 모양으로 쓴다.

## 결론

실제 작업(저와 대화하며 nixos 수정·빌드)에서 `nixup` 빌드의 에너지 비중은 작다

## 상세

**실제 작업(저와 대화하며 nixos 수정·빌드)에서 `nixup` 빌드의 에너지 비중은 작다**: 오늘 배터리 구간의 nix 빌드/적용 9회, 총 24분, psys 7.4~11.5 W(기준선 대비 **+4.1~5.5 W**, CPU 10~22%〔구표기 L6: **전체 CPU 대비**(확인: 저장 샘플 빌드 57개에서 전체 대비 중앙값 10.3%, 코어 1개 기준으로 환산하면 nix 계열이 중앙값 약 129% = 약 1.3코어)〕), 회당 증가분 0.03~0.39 Wh, **합계 약 1.8 Wh ≈ 배터리의 3.3%**(약 54.9 Wh 기준)

## 수준

**측정(9회, psys 기준; 배터리 V×I 로는 약 1 W 더 큼)**

## 근거(조건)

`observectl` 표본에서 nix/nix-daemon 이 보이는 연속 구간을 묶고, 직전 7분의 같은 전원 상태·비빌드 표본 평균을 기준선으로 뺌. 빌드 중 깨어남은 nix-daemon +305/s·nix +294/s(#39)〔구표기 L9: 메인 스레드만, 최소값〕

## 수준을 올리려면

비중이 작으므로 빌드 자체를 줄이는 최적화는 우선순위 낮음. 기준선(디스플레이/PSR, #53·#54)과 내 세션 활동(+0.4~0.6 W, #52)이 더 큼
