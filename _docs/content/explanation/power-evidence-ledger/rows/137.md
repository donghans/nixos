> 장부 #137 행. 원본 `power-evidence.md` 표의 한 줄을 열 단위로 나눈 것이다(내용 변경 없음, 문장 단위로 줄만 바꿈). 새 행은 이 모양으로 쓴다.

## 결론

psys 는 같은 조건 안에서 패키지 전력(pkg)에 거의 정비례하고(기울기 b 는 조건마다 다름), 이를 빼면 창 흔들림이 약 10배 줄어 효과를 「패키지 몫」과 「패키지 밖 몫」으로 가를 수 있다 — R2 짝 맞춤 검증.

## 상세

**psys 는 같은 조건 안에서 패키지 전력(pkg)에 거의 정비례하고(기울기 b 는 조건마다 다름), 이를 빼면 창 흔들림이 약 10배 줄어 효과를 「패키지 몫」과 「패키지 밖 몫」으로 가를 수 있다 — R2 짝 맞춤 검증.** 기존 ABAB 결과 6개(`il1`·`nt-kf`·`bt1`·`tm1`·`br1`·`oc1`)를 같은 조건 블록(창 번호가 다시 0 으로 돌아오는 곳이 새 블록) 단위로 나누고, 조건 평균을 뺀 창 값으로 psys~pkg 기울기 b 를 시험마다 구함.
**덮개 열림·AC 모드: il1 4.69·nt-kf 4.74·bt1 4.88·tm1 4.85, 밝기 시험 br1 3.95(조건 간 밝기가 달라 낮게 나옴), 덮개 닫힘·배터리: oc1 2.47(오염 블록 뺌, 포함하면 2.71)**.
창 psys 표준편차 → b 를 뺀 잔차: il1 0.132→0.013, nt-kf 0.134→0.010, bt1 0.152→0.010, tm1 0.126→0.010, br1 0.104→0.026, oc1(오염 뺌) 0.127→0.006 W. 쌍별 효과(B−A)를 Δpsys = b·Δpkg + 밖 몫 으로 가른 값: **KFENCE(nt-kf, 4쌍) +0.181 = +0.180 + 0.001, 주기 타이머(tm1, 3쌍) +0.259 = +0.252 + 0.008, 밝기 5−100%(br1, 3쌍) −0.797 = +0.011 + −0.807, 입력 잠금(il1, 4쌍) +0.004 = −0.001 + 0.005, 블루투스(bt1, 3쌍) −0.016 = +0.009 + −0.024, 덮개 닫힘·배터리 수집기 켬/끔(oc1 오염 블록 뺌, 3쌍) +0.110 = +0.114 + −0.004** — KFENCE·타이머는 전부 패키지 몫, 밝기는 전부 패키지 밖 몫으로 갈려 이미 알려진 사실(밝기는 화면, KFENCE·타이머는 CPU)과 맞는다.
**정정**: 이 행의 첫 판에는 oc1 의 오염된 마지막 켬 블록(#127 이 제외한 것, 2.94·2.95·3.12 W 창 포함)이 들어 있어 oc1 이 +0.479 W·b 2.71 로 나왔고, il1 은 연속된 같은 조건 블록이 합쳐져 −0.046 W 로 잘못 나왔다(#128 의 +0.004 W 가 맞다).
대화 중 상시 기록(7일, 5분 구간, 덮개·AC·밝기가 같은 그룹)에서 먼저 얻은 b 2.3~2.9 는 사용·시험 상태가 섞인 값이라 쓰지 않는다.
한계: **b 를 같은 창에서 구해 소음 감소 폭이 부풀려짐**(다른 시험의 b 를 같은 조건 시험에 적용하는 검증은 안 함), 블록 쌍이 3~4개뿐, 덮개 닫힘·배터리 b 는 시험 하나(블록 7개)에서 나옴.
효과 판정 기준(0.3 W)·정책 근거로는 쓰지 않는다.
