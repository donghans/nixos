## 상세

**(#133 으로 무효화: 프로그램 끄기가 서비스 워커를 멈추지 못했음)** **첫째 프로필 Vivaldi 의 확장 4개를 하나씩·전부 꺼도 앱 CPU·깨움·psys 가 줄지 않는다 — 확장 4개는 주기 활동의 원인이 아니다(#125 와 어긋남).** 덮개 열림·AC·`tlp bat`·빈 화면(Vivaldi 만)·입력 장치 잠금(#128 도구), 노트북 시계 11:23~12:15, 조건 7개(모두 켬·모두 끔·번호 0/1/2/3 각각 끔·모두 켬) 각 안정화 240초+45초 창 4개, 끄기는 실행 중 `chrome.management.setEnabled`(원격 디버깅 포트), 조건마다 다시 켬.
**모든 조건의 첫 창이 6~10 W·깨움 700~1200/s 로 튀어(안정화 직후, 측정 쪽 영향 추정) 제외**하면 앱 CPU 약 0.06 s/s 로 전 조건 같고(모두 켬 0.057·0.013·0.057, 모두 끔 0.054·0.061·0.063), 모두 끔이 켬보다 낮지 않다.
창 3개 중 하나꼴로 앱 CPU 0.01 로 떨어지는 주기적 변동(모두 끔·번호 2 끔에서는 안 보임)은 확장 여부와 무관해 보임.
**#125(`--disable-extensions`, 앱 CPU 0.06→0.003)와 어긋남** — 그 플래그는 시작 때 Vivaldi 내부 확장도 같이 끄고 이번엔 사용자 확장만 끈 데다 시작 페이지가 달라(`about:blank`) 원인 미확인.
