# 장부 #28 — 일반 부팅(pcie_aspm=off+acpi_osi=Linux+irqpoll)이 no-quirks 보다 쉬는 전력이 높다 — 배터리 기준 실제 비용은 작다: 낮은 상태…

> 장부 #28 행. 원본 `power-evidence.md` 표의 한 줄을 열 단위로 나눈 것이다(내용 변경 없음, 문장 단위로 줄만 바꿈). 새 행은 이 모양으로 쓴다.

## 결론

일반 부팅(`pcie_aspm=off`+`acpi_osi=Linux`+`irqpoll`)이 no-quirks 보다 쉬는 전력이 높다 — **배터리 기준 실제 비용은 작다**: 낮은 상태 +0.09±0.06 W(통계적으로 구분 안 됨), 높은 상태 +0.21±0.06 W(유의, 전체의 약 4%)

## 근거(조건)

사무실 Wi-Fi, 덮개 닫힘, VT2, 수집기 L0. 배터리 V×I: 낮음 3.67±0.48(n=287) → 3.76±0.36(n=45), 높음(둘 다 tty1 다녀온 뒤) 5.40 → 5.61±0.21(n=24). psys 는 더 크게 나옴(낮음 +0.40, 높음 +0.82 W)이나 **#31 에서 psys 가 총 소비의 일부(약 1 W 누락)만 본다고 확인**돼 부팅 간 절대 비교에는 쓰지 않음. 패키지 C-state 는 일반이 덜 깊다(낮음 pc10 47 → 28%, 높음 pc8 45 → 30%)
