② 시작 페이지를 `about:blank` 로 바꿔도(10구간×45초) 같은 활동이 계속: 앱 CPU 0.05~0.065 구간과 0.011 구간이 섞이고 psys 2.4~4.9 W. ③ 동기화를 끄고(`--disable-sync`)도 같음: 앱 CPU 0.056~0.072 구간 7개, 0.010·0.026 구간 2개, psys 2.35~4.5 W. 즉 시작 페이지 위젯이나 동기화가 원인이 아니다.
