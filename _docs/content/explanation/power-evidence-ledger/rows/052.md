# 장부 #52 — Wayland(VT1)가 활성일 때 내 Claude 세션의 활동은 전력을 올린다 — 단 kmscon 비용은 없음…

> 장부 #52 행. 원본 `power-evidence.md` 표의 한 줄을 열 단위로 나눈 것이다(내용 변경 없음, 문장 단위로 줄만 바꿈). 새 행은 이 모양으로 쓴다.

## 결론

Wayland(VT1)가 활성일 때 내 Claude 세션의 활동은 전력을 올린다 — 단 kmscon 비용은 없음 (PSR 꺼진 상태에서 측정 — PSR 을 켠 지금은 활동이 PSR 을 깨므로 더 클 수 있어 T18 에서 재측정)

## 상세

**Wayland(VT1)가 활성일 때 내 Claude 세션의 활동은 전력을 올린다 — 단 kmscon 비용은 없음 (PSR 꺼진 상태에서 측정 — PSR 을 켠 지금은 활동이 PSR 을 깨므로 더 클 수 있어 T18 에서 재측정)**: kmscon CPU 0%(비활성 VT 는 그리지 않음), Claude CPU 한가함 3~4% ↔ 활동 10~12%〔구표기 L2: 코어 1개=100%〕. psys 한가함 5.17/4.13 W ↔ 활동 5.30/5.15 W(쌍별 +0.12, +1.02, 평균 **+0.57**), 배터리 6.18/5.75 ↔ 6.29/6.36 W(+0.11, +0.61, 평균 **+0.36**), 패키지 2.20/1.82 ↔ 2.25/2.20(+0.05, +0.38, 불확실)

## 수준

**측정(약) — ABAB 2쌍, 두 쌍 모두 같은 부호; 단 크기가 쌍마다 크게 다름**

## 근거(조건)

덮개 열림, 방전 62%, 밝기 5%, Wayland 한가한 데스크톱, 모션 줄임 설정 적용. 한가함 구간끼리도 psys 가 1 W 달랐음(5.17 대 4.13, pc8 32% 대 40%) → Wayland 한가한 상태의 자체 변동 ±0.5 W. 즉 내 활동 비용은 +0.1~1.0 W 범위로 이 변동과 겹침

## 수준을 올리려면

Wayland 측정 중에는 내 세션을 한가하게 두는 것이 안전(활동 시 +0.4 W 안팎)
