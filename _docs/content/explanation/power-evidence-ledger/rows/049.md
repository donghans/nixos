## 근거(조건)

기각: tailscaled(#38), 프록시(#46), 네트워크 종류(#47), 프로세스 깨어남(#39), 터치패드 입력 이벤트(30초 0건), kmscon 터미널 출력(60초 rchar +0). **kmscon 에 `--dpms-timeout`(기본 600초)이 있고 현재 sysfs DPMS 는 Off 인데도 패키지는 PC3** → 화면 출력 꺼짐만으로는 부족. 남은 후보: 18:37~18:51 사이 새로 생긴 장치/세션 상태(재로그인으로 뜬 새 Hyprland·Claude 세션, AC 충전·분리 뒤 TLP 적용), ISH(IRQ26)·I2C(IRQ27) 인터럽트(높은 구간에서만 초당 2~3회), PCI 장치 runtime PM(현재 `00:12.0`·`00:15.0` 은 control=on 이 의도된 상태, 나머지는 auto)

## 수준을 올리려면

**재부팅 후 낮은 상태가 돌아오는지**(세션 요인 vs 하드웨어 요인 분리), 돌아오면 재로그인/충전을 하나씩 재현
