## 결론

키보드·터치패드(마우스) 비활성(`hl.device enabled=false`)이 배터리에 주는 영향은 이 틀에서 안 보인다 — 잠금 −/+0.004 W(소음 ±0.15 W/창).

## 상세

**키보드·터치패드(마우스) 비활성(`hl.device enabled=false`)이 배터리에 주는 영향은 이 틀에서 안 보인다 — 잠금 −/+0.004 W(소음 ±0.15 W/창).** 덮개 열림·AC·`tlp bat`·빈 화면, 노트북 시계 약 10:52~11:23, 잠금 없음/잠금 각 4블록(순서 A·B·B·A·A·B·B·A, 안정화 40초+90초 창 2개).
블록 평균 psys 없음 2.085·1.938·1.891·1.887 W(평균 1.950) ↔ 잠금 1.923·1.872·2.060·1.961 W(평균 1.954), 쌍별 부호 일정치 않음.
pkg 0.60~0.69 W·PSR 잔류 98~99% 도 같다.
깨움 수는 이 도구가 기록하지 않음.
잠금은 사용자의 터치패드 토글·힌지 키보드 정책과 같은 호출(`hyprctl eval hl.device`)이며 풀 때 `hypr-input-policy` 로 정책 복원(터치스크린은 평소대로 꺼짐 — 처음 만든 판에서 풀 때 터치스크린이 켜지던 것을 고치고 다시 시험, 앞선 1.5분 시도는 데이터 없음).
한계: 효과가 약 0.1 W 보다 작으면 구별 못 함, 입력이 실제로 막히는지는 사용자 설명에 의존(직접 확인 못 함).
