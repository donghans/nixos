# 장부 #44 — PMC LTR 을 보고하는 장치는 CNV(Wi-Fi/BT) 와 ISH 둘뿐(나머지 0).

> 장부 #44 행. 원본 `power-evidence.md` 표의 한 줄을 열 단위로 나눈 것이다(내용 변경 없음, 문장 단위로 줄만 바꿈). 새 행은 이 모양으로 쓴다.

## 결론

PMC LTR 을 보고하는 장치는 **CNV(Wi-Fi/BT) 와 ISH 둘뿐**(나머지 0).

## 상세

PMC LTR 을 보고하는 장치는 **CNV(Wi-Fi/BT) 와 ISH 둘뿐**(나머지 0).
CNV 는 **2.1 ms ↔ 20.5 ms 로 오르내림**(90초 중 20 ms 대 77%, 2 ms 대 23%).
오전 낮음/높음 스냅샷의 CNV raw 도 낮음 0x8e71(≈20.5 ms) · 높음 0x8c42(≈2.2 ms)로 달랐음

## 수준

**측정(1분 30초, 1초 간격)**

## 근거(조건)

`/sys/kernel/debug/pmc_core/ltr_show`. 하지만 **LTR 이 20 ms 로 느슨한 시간이 77% 인데도 패키지는 PC6 이상에 0%** → CNV LTR 은 *유일한* 차단 요인이 아님

## 수준을 올리려면

낮은 상태일 때 CNV LTR 이 항상 20 ms 인지, 높은 상태일 때 2 ms 대 비율이 큰지 시계열로 대조(수집기에 LTR 추가 필요)
