# 전력·입력 조사 근거 장부 (2026-10-20 기준)

`posture.md` 의 조사 기록에서 **어떤 주장이 어떤 근거 수준인지**를 한 곳에 모은 표. 규칙: 한 번의 관찰이나 상관은 "추정", 번갈아(ABAB) 2쌍 이상에서 모든 쌍이 같은 부호이고 임계(전력 0.3 W) 이상이면 "측정". 수준을 올리려면 마지막 열의 시험이 필요하다. 이후 새 결과는 이 표를 먼저 고친다. (`observectl ab` 가 판정을 자동으로 낸다 — 사용법은 observectl.md)


> **목적과 측정 조건 (2026-10-20 정정)**: 목적은 **Wayland(Hyprland) 세션을 쓰는 동안의 배터리 최적화**다. Claude 를 VT2(kmscon)에서 돌리는 것은 Wayland 세션 위에서 돌릴 때 생기는 변수를 줄이기 위한 **측정 위생**이며 원격 제어(RC) 용도가 아니다.
> 지금까지의 시험 대부분은 **덮개 닫힘 + VT2 활성**(패널 꺼짐, Hyprland 는 뒤에서 대기)이라는 **대리(proxy) 조건**에서 했다. 실제 사용(덮개 열림, 패널 켜짐, Wayland 활성)과 다르므로 아래 결과가 실제 사용에서도 유효한지는 **#37 에서 따로 확인**해야 한다. 내 Claude 세션의 부하(#34)는 사용자가 줄일 소비가 아니라 **측정에 섞이는 교란 요인**이다.
